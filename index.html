Components

Everything a product needs.
Nothing it doesn't.

Forms, overlays, navigation, data display and feedback, built on Radix-style accessibility patterns. These are live components, not screenshots. Go ahead and click them.

Motion

Effects that make people stop scrolling.

Text effects, scroll reveals, magnetic buttons, tilt cards, spotlights, docks and marquees. Each one is a data attribute, runs at 60fps, and turns itself off for people who prefer reduced motion.

Backgrounds

One div. Instant atmosphere.

Aurora, mesh, particles, meteors, retro grids, light rays and more. Canvas backgrounds pause when they scroll offscreen, so they cost nothing.

Micro-interactions

The details are the design.

Like bursts, morphing icons, download buttons, day-night toggles, odometers and more than 20 loaders, ready to drop in.

Theming

Your brand in one number.

Every color is derived from a single OKLCH --hue, including focus rings, soft fills, glows and charts. Pick one below and the whole page follows.

/* that's the whole theme */
:root { --hue: 252; --radius: .625rem; }

Developer experience

Write HTML. Get an app.

  • Auto-mounting. Inject HTML with htmx, Turbo, Alpine or innerHTML and components wire themselves up, then clean up when removed.
  • Accessible by default. Focus traps, roving tabindex, ARIA wiring, and Escape that closes only the topmost layer.
  • Take only what you need. Use the full bundle, a per-group bundle, or individual source files.
  • Framework agnostic. Works in Rails, Django, Laravel, Astro, Hugo, React and Vue, anywhere that renders HTML.
